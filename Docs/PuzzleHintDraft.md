# Borrador de pistas del cofre

Propuesta de trabajo para la rama `Feature_Puzzle`. Antes de incorporarla al juego se debe decidir dónde aparece la pista y si revelarla reduce demasiado la dificultad.

- Primera pista: observar los objetos situados junto a la puerta.
- Segunda pista: el código tiene cuatro cifras.
- Tercera pista: consultar el texto detrás de la puerta.

Este borrador no forma parte de la corrección de validación.
